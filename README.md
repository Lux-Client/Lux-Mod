# Lux Client Mod

Ready-to-use jars of the Lux Client mod for Fabric:
**[Releases](https://github.com/Lux-Client/Lux-Mod/releases)**

Put the matching jar (`Lux-Client-mc<Minecraft version>-<version>.jar`) into your `mods` folder.
Requires Fabric and Fabric API. Even easier: in the [Lux Launcher](https://github.com/Lux-Client/Lux-Client),
open a matching instance and click "Install Lux Client".

Supported: Minecraft 1.21.11, 1.21.8, 26.2 and 1.20.1 (Fabric).
